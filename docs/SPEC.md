# DDR WORLD フレアスキル目標ボード

ローカル版の実装着手日は2026-10-30。GitHub Pages公開仕様を2026-11-19に追加。

## 目的と管理単位
将来対象にしたいSPの90譜面を管理する。公式の現在対象90譜面の再現ではない。CLASSIC / WHITE / GOLD各30譜面まで。踊・激・鬼を扱い、同一曲の別譜面は別対象、同一譜面は重複不可。未充足で利用可。

## ランク・達成・順序
目標FL9/FLEX、現在なし/FL9/FLEX。なしは未プレー・未記録・FL8以下。FL9目標はFL9またはFLEXで達成、FLEX目標はFLEXのみ達成。最高ランクを手動編集する。履歴は持たない。
各区分は目標スキル降順、同値は曲名と譜面順。現在変更で順序は変わらず、目標変更で再計算。数値未確認の譜面は末尾、合計は未確認件数付きで表示し、0として確定扱いしない。

## 画面・登録
PC優先の横3列、各列最大30のコンパクト行。ジャケット・曲名・譜面・レベル・目標・目標スキル・現在・達成表示。達成行も残す。区分別/全体に登録数・達成数・目標合計。現在スキルは算出しない。
検索は曲名、区分、レベル、譜面で絞る。複数選択→目標一括指定/個別変更→確認→まとめて登録。初期現在はなし。貼り付けは1行1曲、候補を明示し、曖昧一致や複数候補を自動確定しない。未一致行は修正可。目標/現在は一覧で変更、削除・入替可。

## ローカル版での保存
曲/譜面JSONとユーザー登録IndexedDBを分離。自動保存・再起動復元。JSONバックアップはバージョンを持ち、全件検証後に単一トランザクションで置換。無効ファイルでは既存データを変更しない。復元前に件数を確認。マスター不在譜面は登録時スナップショットを残し要確認表示、削除しない。

## GitHub Pages版

ローカル版で選定済みの90譜面を初回公開データとする。譜面ID・目標ランク・現在ランクをGitで管理する。公開ページでは譜面ごとの現在ランクと目標の達成状況、全体と区分別の達成件数を表示する。譜面の入れ替えやランク変更は、開いているページ内で反映する。ページを再読み込みすると公開データに戻る。公開データはローカル版のバックアップから生成し、コミットとプッシュで反映する。

## データ
公式優先、取得元/取得日を保存。通常閲覧で外部アクセスなし。画像はローカル。更新スクリプトはアプリから独立しユーザーデータに触れない。公式で確認できない区分/数値はnullとし推測しない。出典付き補足JSONで確認結果を追加できる。
曲: id/title/category/jacket/source/retrievedAt/categorySource。譜面: id/songId/style/difficulty/level/skills。登録: chartId/target/current/createdAt/updatedAt/snapshot。

## 対象外
DP、FL8以下詳細、履歴、自動同期、補欠、自動推薦、アプリ内アカウント。

## 検証条件
各区分30制限、重複防止、達成表、目標順、検索/複数/貼付、保存復元、バックアップ検証、孤立譜面保全、外部接続不要。データ網羅性と未確認項目はDATA-SOURCES.mdに記録する。
